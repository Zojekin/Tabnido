## Key Features

- **Real Interaction Detection** – Deeply monitors physical inputs like keystrokes, clicks, drags, and page scrolling at the webpage level. Accurately identifies genuine reading and active usage, avoiding premature closures caused merely by background switching.
- **Flexible Inactivity Timers** – Granular countdown customization supporting minutes, hours, days, and months.
- **Domain Whitelist Protection** – In-place inline editing and robust URL matching rules to protect critical tabs.
- **Searchable Archive & Fast Restore** – Preserves up to 500 closed tab snapshots with real-time title/URL search and instant one-click restoration.

## Installation & Usage

1. Go to the [Releases](https://github.com/Zojekin/Tabnido/releases) page, download the latest package `tabnido-1.0.0.zip`, and unzip it locally;
2. Open any Chromium-based browser (Google Chrome, Microsoft Edge, Brave, etc.):
   - Chrome: navigate to `chrome://extensions`
   - Edge: navigate to `edge://extensions`
3. Toggle on **"Developer mode"** in the top-right corner;
4. Click **"Load unpacked"** in the top-left corner and select the unzipped directory;
5. Pin the **Tabnido** icon to your browser toolbar and click it to configure.
